## Overview

`PromptRegistry` is not exported from `@frontmcp/sdk`: reach it through `scope.prompts`, and name its type as `ScopeEntry['prompts']`. Inside a tool, resource or prompt, `this.scope` is the scope serving the call.

```typescript
import type { ScopeEntry } from '@frontmcp/sdk';

type PromptRegistry = ScopeEntry['prompts'];

// Access via scope
const prompts: PromptRegistry = scope.prompts;

// List all prompts
const allPrompts = prompts.getPrompts();

// Find a specific prompt
const prompt = prompts.findByName('code_review');
```

## Methods

### getPrompts()

Get all prompts (local + adopted).

```typescript
getPrompts(includeHidden?: boolean): PromptEntry[]
```

| Parameter       | Type      | Default | Description            |
| --------------- | --------- | ------- | ---------------------- |
| `includeHidden` | `boolean` | `false` | Include hidden prompts |

**Example:**

```typescript
// Get all visible prompts
const prompts = registry.getPrompts();

// Include hidden prompts
const allPrompts = registry.getPrompts(true);
```

### findByName()

Find a prompt by its base name.

```typescript
findByName(name: string): PromptEntry | undefined
```

**Example:**

```typescript
const prompt = registry.findByName('code_review');
if (prompt) {
  console.log(`Found: ${prompt.metadata.description}`);
}
```

### findAllByName()

Find all prompts matching a name (when multiple exist).

```typescript
findAllByName(name: string): PromptEntry[]
```

**Example:**

```typescript
// When multiple apps define 'greeting' prompt
const prompts = registry.findAllByName('greeting');
for (const prompt of prompts) {
  console.log(`${prompt.fullName}: ${prompt.metadata.description}`);
}
```

### getExported()

Lookup a prompt by its exported (resolved) name: the name [`exportResolvedNames(opts)`](#exportresolvednames) gives it, compared exactly.

```typescript
getExported(name: string, opts?: PromptExportOptions): PromptEntry | undefined
```

**Example:**

```typescript
const prompt = registry.getExported('code_review');
```

### exportResolvedNames()

Produce unique, conflict-aware exported names.

```typescript
exportResolvedNames(opts?: PromptExportOptions): Array<{ name: string; instance: PromptEntry }>
```

`PromptExportOptions` (not exported from `@frontmcp/sdk`) takes the same fields as the tool registry's [`ExportNameOptions`](/frontmcp/sdk-reference/registries/tool-registry#exportresolvednames): `case` (default `'snake'`), `maxLen` (default `64`), `prefixChildrenOnConflict` (default `true`) and `prefixSource` (default `'provider'`).

**Example:**

```typescript
const exportedNames = registry.exportResolvedNames();
// code_review → app1:code_review
// app2_code_review → app2:code_review (conflict resolved)
```

### getInlinePrompts()

Get prompts defined inline (local only).

```typescript
getInlinePrompts(): PromptEntry[]
```

### listAllInstances()

List all prompt instances (locals + adopted).

```typescript
listAllInstances(): ReadonlyArray<PromptEntry>
```

### listByOwner()

List prompts by owner path.

```typescript
listByOwner(ownerPath: string): ReadonlyArray<PromptEntry>
```

**Example:**

```typescript
const appPrompts = registry.listByOwner('my-app');
```

### registerPromptInstance()

Register a pre-constructed prompt entry directly.

```typescript
registerPromptInstance(prompt: PromptEntry): void
```

<Note>
Typically used internally for remote app prompts.
</Note>

### subscribe()

Subscribe to prompt change events.

```typescript
subscribe(
  opts: { immediate?: boolean; filter?: (i: PromptEntry) => boolean },
  cb: (event: PromptChangeEvent) => void
): () => void
```

**Returns:** Unsubscribe function.

**Example:**

```typescript
const unsubscribe = registry.subscribe({}, (event) => {
  console.log(`Prompt change: ${event.kind} (v${event.version})`);
});

// Later
unsubscribe();
```

### getCapabilities()

Get MCP capabilities for prompts.

```typescript
getCapabilities(): Partial<ServerCapabilities>
```

**Example:**

```typescript
const caps = registry.getCapabilities();
// { prompts: { listChanged: true } }
```

### hasAny()

Check if any prompts exist.

```typescript
hasAny(): boolean
```

### adoptFromChild()

Adopt prompts from a child registry.

```typescript
adoptFromChild(child: PromptRegistry, _childOwner: EntryOwnerRef): void
```

## Change Events

```typescript
interface PromptChangeEvent {
  kind: 'added' | 'updated' | 'removed' | 'reset';
  changeScope: 'global' | 'session';
  version: number;
  snapshot: ReadonlyArray<PromptEntry>;
  sessionId?: string;
  relatedRequestId?: string;
}
```

## Indexes

| Index            | Key           | Description              |
| ---------------- | ------------- | ------------------------ |
| `byQualifiedId`  | `qualifiedId` | Unique identifier lookup |
| `byName`         | `name`        | Base name lookup         |
| `byOwnerAndName` | `owner:name`  | Scoped name lookup       |
| `byOwner`        | `ownerPath`   | All prompts by owner     |

## Prompt Arguments

Prompts can define required and optional arguments:

```typescript
@Prompt({
  name: 'code_review',
  description: 'Review code for best practices',
  arguments: [
    { name: 'language', description: 'Programming language', required: true },
    { name: 'style', description: 'Review style', required: false },
  ],
})
class CodeReviewPrompt extends PromptContext { }
```

Arguments are validated when the prompt is called:

```typescript
const entry = registry.findByName('code_review');
// entry?.metadata.arguments contains the argument definitions
```
