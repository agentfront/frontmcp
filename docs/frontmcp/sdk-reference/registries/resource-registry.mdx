## Overview

`ResourceRegistry` is not exported from `@frontmcp/sdk`: reach it through `scope.resources`, and name its type as `ScopeEntry['resources']`. Inside a tool, resource or prompt, `this.scope` is the scope serving the call.

```typescript
import type { ScopeEntry } from '@frontmcp/sdk';

type ResourceRegistry = ScopeEntry['resources'];

// Access via scope
const resources: ResourceRegistry = scope.resources;

// List all static resources
const allResources = resources.getResources();

// List all resource templates
const templates = resources.getResourceTemplates();

// Find by URI
const resource = resources.findByUri('file:///config.json');
```

## Methods

### getResources()

Get all static resources (not templates).

```typescript
getResources(includeHidden?: boolean): ResourceEntry[]
```

| Parameter       | Type      | Default | Description              |
| --------------- | --------- | ------- | ------------------------ |
| `includeHidden` | `boolean` | `false` | Include hidden resources |

**Example:**

```typescript
// Get all visible resources
const resources = registry.getResources();

// Include hidden resources
const allResources = registry.getResources(true);
```

### getResourceTemplates()

Get all resource templates.

```typescript
getResourceTemplates(): ResourceEntry[]
```

**Example:**

```typescript
const templates = registry.getResourceTemplates();
for (const template of templates) {
  console.log(`Template: ${template.uriTemplate}`);
}
```

### findByUri()

Find a resource by exact URI match.

```typescript
findByUri(uri: string): ResourceEntry | undefined
```

**Example:**

```typescript
const resource = registry.findByUri('file:///config.json');
if (resource) {
  console.log(`Found: ${resource.name}`);
}
```

### matchTemplateByUri()

Match a URI against template resources.

```typescript
matchTemplateByUri(uri: string): {
  instance: ResourceEntry;
  params: Record<string, string>;
} | undefined
```

**Example:**

```typescript
// Given template: 'file:///users/{userId}/profile'
const match = registry.matchTemplateByUri('file:///users/123/profile');
if (match) {
  console.log(match.instance.name); // user-profile
  console.log(match.params); // { userId: '123' }
}
```

### findResourceForUri()

Find resource by URI (exact match or template). `params` is empty for an exact match.

```typescript
findResourceForUri(uri: string): {
  instance: ResourceEntry;
  params: Record<string, string>;
} | undefined
```

**Example:**

```typescript
// Will try exact match first, then template matching
const found = registry.findResourceForUri('file:///users/123/profile');
console.log(found?.instance.name, found?.params); // user-profile { userId: '123' }
```

### getExported()

Lookup a resource by its exported (resolved) name: the name [`exportResolvedNames(opts)`](#exportresolvednames) gives it, compared exactly.

```typescript
getExported(name: string, opts?: ResourceExportOptions): ResourceEntry | undefined
```

### exportResolvedNames()

Produce unique, conflict-aware exported names.

```typescript
exportResolvedNames(opts?: ResourceExportOptions): Array<{ name: string; instance: ResourceEntry }>
```

`ResourceExportOptions` (not exported from `@frontmcp/sdk`) takes the same fields as the tool registry's [`ExportNameOptions`](/frontmcp/sdk-reference/registries/tool-registry#exportresolvednames): `case` (default `'snake'`), `maxLen` (default `64`), `prefixChildrenOnConflict` (default `true`) and `prefixSource` (default `'provider'`).

### getInlineResources()

Get resources defined inline (local only).

```typescript
getInlineResources(): ResourceEntry[]
```

### listAllInstances()

List all resource instances (locals + adopted).

```typescript
listAllInstances(): ReadonlyArray<ResourceEntry>
```

### listByOwner()

List resources by owner path.

```typescript
listByOwner(ownerPath: string): ReadonlyArray<ResourceEntry>
```

### registerResourceInstance()

Register a pre-constructed ResourceEntry directly.

```typescript
registerResourceInstance(resource: ResourceEntry): void
```

### registerDynamicResource()

Register a resource or template at runtime: a `@Resource` or `@ResourceTemplate` class, a function resource built with `resource()` or `resourceTemplate()`, or a resource record. A resource whose token is already registered is skipped.

```typescript
registerDynamicResource(resourceDef: ResourceType | ResourceRecord | ResourceTemplateRecord): void
```

**Example:**

```typescript
import { resource } from '@frontmcp/sdk';

const RuntimeConfig = resource({
  name: 'dynamic-config',
  uri: 'config://runtime',
  description: 'Runtime configuration',
  mimeType: 'application/json',
})((uri) => ({
  contents: [{ uri, text: JSON.stringify(config) }],
}));

// Register a dynamic resource
registry.registerDynamicResource(RuntimeConfig);
```

### subscribe()

Subscribe to resource change events.

```typescript
subscribe(
  opts: { immediate?: boolean; filter?: (i: ResourceEntry) => boolean },
  cb: (event: ResourceChangeEvent) => void
): () => void
```

**Returns:** Unsubscribe function.

**Example:**

```typescript
const unsubscribe = registry.subscribe({}, (event) => {
  console.log(`Resource change: ${event.kind} (v${event.version})`);
  if (event.updatedUri) {
    console.log(`Updated URI: ${event.updatedUri}`);
  }
});

// Later
unsubscribe();
```

### getCapabilities()

Get MCP capabilities for resources.

```typescript
getCapabilities(): Partial<ServerCapabilities>
```

**Example:**

```typescript
const caps = registry.getCapabilities();
// { resources: { subscribe: true, listChanged: true } }
```

Both flags are `true` when the registry holds any resource.

### hasAny()

Check if any resources exist.

```typescript
hasAny(): boolean
```

### adoptFromChild()

Adopt resources from a child registry.

```typescript
adoptFromChild(child: ResourceRegistry, _childOwner: EntryOwnerRef): void
```

## Change Events

```typescript
interface ResourceChangeEvent {
  kind: 'added' | 'updated' | 'removed' | 'reset';
  changeScope: 'global' | 'session';
  version: number;
  snapshot: ReadonlyArray<ResourceEntry>;
  sessionId?: string;
  relatedRequestId?: string;
  /** URI of the specific resource whose content changed (for kind: 'updated') */
  updatedUri?: string;
}
```

## Indexes

| Index           | Key           | Description                |
| --------------- | ------------- | -------------------------- |
| `byQualifiedId` | `qualifiedId` | Unique identifier lookup   |
| `byName`        | `name`        | Base name lookup           |
| `byUri`         | `uri`         | Static resource URI lookup |
| `byUriTemplate` | `uriTemplate` | Template URI lookup        |
| `byOwner`       | `ownerPath`   | All resources by owner     |

## Static vs Template Resources

<CardGroup cols={2}>
  <Card title="Static Resources" icon="file">
    Have a fixed `uri` property. Found via `findByUri()`.
  </Card>
  <Card title="Template Resources" icon="puzzle-piece">
    Have a `uriTemplate` with parameters. Matched via `matchTemplateByUri()`.
  </Card>
</CardGroup>

**Example:**

```typescript
// Static resource
@Resource({
  name: 'config',
  uri: 'file:///config.json',
})
class ConfigResource extends ResourceContext { }

// Template resource
@ResourceTemplate({
  name: 'user-profile',
  uriTemplate: 'file:///users/{userId}/profile',
})
class UserProfileResource extends ResourceContext<{ userId: string }> { }
```
