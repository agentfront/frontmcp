## Overview

`AgentRegistry` is not exported from `@frontmcp/sdk`: reach it through `scope.agents`, and name its type as `ScopeEntry['agents']`. Inside a tool, resource or prompt, `this.scope` is the scope serving the call.

```typescript
import type { ScopeEntry } from '@frontmcp/sdk';

type AgentRegistry = ScopeEntry['agents'];

// Access via scope
const agents: AgentRegistry = scope.agents;

// List all agents
const allAgents = agents.getAgents();

// Find by ID
const agent = agents.findById('research-agent');

// Get agents as callable tools
const agentTools = agents.getAgentsAsTools();
```

## Methods

### getAgents()

Get all agents (local + adopted).

```typescript
getAgents(includeHidden?: boolean): AgentEntry[]
```

| Parameter       | Type      | Default | Description           |
| --------------- | --------- | ------- | --------------------- |
| `includeHidden` | `boolean` | `false` | Include hidden agents |

**Example:**

```typescript
const agents = registry.getAgents();
for (const agent of agents) {
  console.log(`Agent: ${agent.id} - ${agent.metadata.description}`);
}
```

### findById()

Find an agent by its ID.

```typescript
findById(id: string): AgentEntry | undefined
```

**Example:**

```typescript
const agent = registry.findById('research-agent');
if (agent) {
  console.log(`Found: ${agent.name}`);
}
```

### findByName()

Find an agent by its name.

```typescript
findByName(name: string): AgentEntry | undefined
```

**Example:**

```typescript
const agent = registry.findByName('research');
```

### getVisibleAgentsFor()

Get agents visible to a specific agent.

```typescript
getVisibleAgentsFor(agentId: string): AgentEntry[]
```

**Example:**

```typescript
// Get agents that 'orchestrator' can call
const visibleAgents = registry.getVisibleAgentsFor('orchestrator');
```

### getAgentsAsTools()

Get the MCP tool definitions of the agents visible to other agents.

```typescript
getAgentsAsTools(): Tool[]
```

Each agent is exposed as a tool named `invoke_<agent id>`, so it can be called by other agents or the MCP client.

**Example:**

```typescript
const agentTools = registry.getAgentsAsTools();
// Each agent becomes a callable tool with its input schema
```

### getAgentToolsFor()

Get tool definitions for agents visible to a specific agent.

```typescript
getAgentToolsFor(agentId: string): Tool[]
```

**Example:**

```typescript
// Get tools available to 'coordinator' agent
const tools = registry.getAgentToolsFor('coordinator');
```

### getInlineAgents()

Get only agents defined inline in this registry.

```typescript
getInlineAgents(): AgentEntry[]
```

### listAllInstances()

List all agent instances (locals + adopted).

```typescript
listAllInstances(): ReadonlyArray<AgentEntry>
```

### subscribe()

Subscribe to agent change events.

```typescript
subscribe(
  opts: { immediate?: boolean; filter?: (i: AgentInstance) => boolean },
  cb: (event: AgentChangeEvent) => void
): () => void
```

**Returns:** Unsubscribe function.

**Example:**

```typescript
const unsubscribe = registry.subscribe({}, (event) => {
  console.log(`Agent ${event.kind} (v${event.version}):`, event.agentId ?? 'n/a');
});

// Later
unsubscribe();
```

### getCapabilities()

Get MCP capabilities for agents. Agents are served as tools, so this is `{ tools: { listChanged: true } }` when the registry holds any agent, and `{}` otherwise.

```typescript
getCapabilities(): Partial<ServerCapabilities>
```

### hasAny()

Check if any agents exist.

```typescript
hasAny(): boolean
```

### adoptFromChild()

Adopt agents from a child registry.

```typescript
adoptFromChild(child: AgentRegistry, _childOwner: EntryOwnerRef): void
```

### removeChild()

Remove a child registry and clean up subscriptions.

```typescript
removeChild(child: AgentRegistry): void
```

### dispose()

Dispose registry and clean up all child subscriptions.

```typescript
dispose(): void
```

## Change Events

```typescript
interface AgentChangeEvent {
  kind: 'added' | 'updated' | 'removed' | 'reset'
      | 'execution_start' | 'execution_complete' | 'execution_error';
  changeScope: 'global' | 'scope' | 'app' | 'plugin' | 'agent';
  version: number;
  snapshot: readonly AgentInstance[];
  /** ID of the affected agent (for single-agent events) */
  agentId?: string;
  agentFullName?: string;
  owner?: { kind: AgentChangeScope; id: string };
  timestamp?: number;
  execution?: {
    runId: string;
    input?: unknown;
    output?: unknown;
    error?: Error;
    durationMs?: number;
  };
}
```

| Index           | Key           | Description                               |

| `byQualifiedId` | `qualifiedId` | Unique identifier lookup                  |

## Agent Visibility

Agents can control which other agents they can see and call, through `swarm`:

```typescript
@Agent({
  id: 'coordinator',
  name: 'Coordinator',
  description: 'Coordinates research tasks',
  llm: { provider: 'openai', model: 'gpt-4o', apiKey: { env: 'OPENAI_API_KEY' } },
  swarm: {
    canSeeOtherAgents: true,
    visibleAgents: ['researcher', 'writer'], // Can only call these agents
  },
})
class CoordinatorAgent extends AgentContext { }
```

Use `getVisibleAgentsFor()` to query visibility:

```typescript
const visible = registry.getVisibleAgentsFor('coordinator');
// Returns only 'researcher' and 'writer' agents
```

## Agents as Tools

Agents are automatically registered in the parent scope's ToolRegistry, as `invoke_<agent id>`:

```typescript
@Agent({
  id: 'research',
  name: 'Research Agent',
  llm: { provider: 'openai', model: 'gpt-4o', apiKey: { env: 'OPENAI_API_KEY' } },
  inputSchema: {
    topic: z.string(),
    depth: z.enum(['shallow', 'deep']),
  },
})
class ResearchAgent extends AgentContext { }

// The agent becomes callable as a tool
await client.callTool('invoke_research', {
  topic: 'AI advancements',
  depth: 'deep',
});
```
