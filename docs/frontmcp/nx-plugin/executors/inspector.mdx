Launches the MCP Inspector UI for testing and debugging your server's tools, resources, and prompts.

## Usage

```bash
nx inspector my-app
```

## Configuration

```json project.json
{
  "targets": {
    "inspector": {
      "executor": "@frontmcp/nx:inspector",
      "options": {}
    }
  }
}
```

## Options

| Option | Type     | Description                                                              |
| ------ | -------- | ------------------------------------------------------------------------ |
| `port` | `number` | Inspector UI port. Passed to the inspector via the `CLIENT_PORT` env var |

The `frontmcp inspector` command takes no flags, so the executor forwards `port` as the `CLIENT_PORT` environment variable instead.

## Behavior

- Opens the MCP Inspector at `http://localhost:6274`
- Connect to your running server to browse and test capabilities
- **Not cacheable**: Interactive, long-running process
